# 星河巨影 (GTSRA) 本地化术语表 (Localization Glossary)

本文档为 **星河巨影 (GTSRA)** Mod 的官方中英文对照术语表。在进行本地化翻译（尤其使用大语言模型 / AI 翻译）时，**必须严格遵循**本表中的规范译名，避免出现译名漂移或不一致。

> [!IMPORTANT]
> 1. **严禁混用译名**：例如“希诺”统一翻译为 `Xino`（禁止使用 Xinuo 或 Xilonen）；“舰娘”统一翻译为 `Shipgirl`（禁止使用 Kanmusu）；“巨娘”统一翻译为 `Giantess`。
> 2. **群星原版对齐**：民事理念 $\to$ `Civic`、特质 $\to$ `Trait`、起源 $\to$ `Origin`、岗位 $\to$ `Job`、区划 $\to$ `District`。
> 3. **保留格式符**：游戏内的变量引用（如 `[Root.GetName]`）、代码占位符（如 `$trait_xxx$`）及颜色标签（如 `§Y...§!`）必须原样保留。
